Search
GET /search/pinterest?q={query} Pinterest Image Search
// parameters
PARAM TYPE STATUS DESCRIPTION
q string REQUIRED Search keyword (e.g. anime, sunset)
// example request
# GET request
GET /search/pinterest?q=aesthetic
// example response

// response schema
status boolean Request success flag
query string The search keyword used
total number Number of results returned (max 20)
data[].id string Pinterest pin ID
data[].caption string Pin title / grid caption
data[].image string Original image URL (direct link)
data[].source string Pin URL on Pinterest
data[].uploader object Pinner info: username, fullname, followers
Error Codes
400 Bad Request Missing required parameter
404 Not Found No results found for the query
429 Too Many Requests Rate limit exceeded (60 req/min)
500 Server Error Upstream scraping failed
